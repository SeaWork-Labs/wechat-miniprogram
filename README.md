# wechat-miniprogram

微信小程序开发框架：页面模板、组件、API 与云开发的完整用法。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/wechat-miniprogram#v1.0.1 --skill wechat-miniprogram
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill wechat-miniprogram
```

## 内容

技能正文在 `skills/wechat-miniprogram/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/wechat-miniprogram/payload/`，不要反向同步。版本以 git tag 为准。
